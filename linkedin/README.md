# Imágenes de LinkedIn · Pana Iluminación

Infografías que se publican en la página de LinkedIn de Pana a través de Buffer.
Buffer toma cada imagen desde su link público de este repositorio, por eso el repo es público.

Una carpeta por semana: `semana-AAAA-MM-DD` (fecha del lunes).

- `INSTRUCCIONES.md`: cómo se arma y se programa cada semana (lo usa la tarea semanal de Claude).
- `temas.md`: registro de temas publicados y banco de ideas.
- `kit/`: estilo visual de Pana (paleta, tipografía Archivo, logos y piezas de ejemplo).
